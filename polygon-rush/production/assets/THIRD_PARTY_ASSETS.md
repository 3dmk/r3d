# Polygon Rush third-party production assets

All runtime 3D assets in this folder are vendored locally so the game does not depend on a third-party CDN at play time.

- Kenney Nature Kit / City Kit-derived environment GLBs (`tree_*`, `rock_*`, `building_*`) sourced from `syuhei176/ai-game-assets`, whose manifest identifies them as Kenney CC0 assets.
- Kenney Starter Kit Racing vehicle and decoration GLBs (`player_car`, `decoration_tents`, `decoration_forest`) sourced from `KenneyNL/Starter-Kit-Racing`; its README states included 3D models and sounds are CC0.
- Three.js r152 GLTFLoader, BufferGeometryUtils and three.module.js are MIT-licensed Three.js runtime files.

Source manifests:
